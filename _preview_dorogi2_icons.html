Финальные варианты (выбранные ранее)

Шоссе — В

Тёмно-серая широкая полоса + белая пунктирная разметка по центру.

Просёлочная — Г

Частая штриховка dasharray «3,2», толщина 2.

Река — Б

Двойной изгиб снизу-слева → верх-справа, толщина 4.

Конюшня — Г

Прямоугольник + надпись «конюшня».

Мост — 5 новых вариантов (скобки ВДОЛЬ шоссе по бокам)

А — П-образные, параллельные шоссе

Сверху ⌐──¬ открыта вниз, снизу ⌐──¬ открыта вверх — обнимают шоссе.

Б — короткие угловые засечки

Четыре уголка по углам моста — только засечки, без перекладин.

В — две длинные горизонтальные линии

Сплошные перила сверху и снизу + засечки на концах.

Г — толстые перила

Толстые чёрные перила сверху и снизу с короткими засечками.

Д — двойные скобки

По две тонкие линии сверху и снизу с засечками — как сдвоенные перила.
